## 이진 탐색 트리의 한계

이진 탐색 트리(BST)는 정렬된 키를 순서대로 삽입하면 편향될 수 있다.\
이 경우 높이가 O(n)이 되어 검색 성능이 선형 탐색과 비슷해진다.

효율적인 이진 탐색 트리를 구성하는 방법에는 서로 다른 두 목적이 있다.

- 최적 이진 탐색 트리: 검색 확률을 반영하여 평균 검색 비용을 최소화한다.
- AVL 트리: 높이 균형을 유지하여 최악의 연산 시간을 제한한다.

## 최적 이진 탐색 트리(Optimal Binary Search Tree)

최적 이진 탐색 트리(OBST)는 주어진 검색 확률에 대해 기대 검색 비용이 최소가 되는 이진 탐색 트리이다.

### 검색 확률과 평균 검색 비용

트리의 높이가 낮다고 반드시 평균 검색 비용이 최소인 것은 아니다.\
자주 검색하는 키가 깊은 위치에 있다면 평균 비교 횟수가 커질 수 있기 때문이다.

따라서 최적 이진 탐색 트리는 높이뿐 아니라 검색 확률과 BST의 키 순서 조건을 함께 고려해야 한다.

### 확장 이진 트리

검색은 트리에 존재하는 키를 찾는 성공 검색과 존재하지 않는 키를 찾는 실패 검색으로 나뉜다.

실패 검색을 분석하기 위해 모든 빈 자식 링크에 가상의 외부 노드를 추가한 트리를 확장 이진 트리(Extended Binary Tree)라고 한다.

내부 노드가 n개이면 외부 노드는 (n + 1)개 이다.

### 성공 검색과 실패 검색의 비용

정렬된 키를 다음과 같이 둔다.
> a<sub>1</sub> < a<sub>2</sub> < ... < a<sub>n</sub>

- p<sub>i</sub>: 키 a<sub>i</sub>를 검색할 확률
- q<sub>i</sub>: 해당 실패 구간에 속하는 키를 검색할 확률

모든 검색은 성공 또는 실패하므로 확률의 합은 1이며, 기대 키 비교 횟수를 최소화하는 트리가 최적 이진 탐색 트리이다.

### 동적 계획법을 이용한 구성

작은 키 구간의 최적 결과를 재사용하는 동적 계획법(Dynamic Programming)을 사용할 수 있다.

계산 순서는 다음과 같다.

1. 빈 구간의 비용과 가중치를 초기화한다.
2. 키가 1개인 구간부터 길이를 늘려 계산한다.
3. 각 구간에서 가능한 루트를 모두 비교한다.
4. 최소 비용과 루트 인덱스를 저장한다.
5. 저장한 루트 정보를 이용하여 트리를 복원한다.

모든 루트 후보를 확인하는 기본 구현은 시간 O(n<sup>3</sup>), 공간 O(n<sup>2</sup>)이다.

## AVL 트리

AVL 트리는 모든 노드에서 왼쪽과 오른쪽 서브트리의 높이 차이를 1 이하로 유지하는 이진 탐색 트리이다.

삽입·삭제로 균형이 깨지면 회전으로 복구한다. 검색 확률을 미리 알 필요가 없으며, 동저긍로 변하는 키 집합을 관리할 수 있다.

### 높이 균형과 균형 인수

높이 균형 조건은 재귀적으로 정의한다.
- 빈 트리는 균형 상태이다.
- 왼쪽과 오른쪽 서브트리는 각각 균형 상태여야 한다.
- 두 서브트리의 높이 차이가 1 이하여야 한다.

루트만 균형을 이루면 되는 것이 아니라 모든 노드에서 조건을 만족해야 한다.

AVL 트리가 반드시 완전 이진 트리인 것은 아니다.

### 회전

회전(Rotation)은 BST의 키 순서를 유지하면서 부모·자식 연결을 바꾸는 연산이다.

삽입한 노드에서 루트 방향으로 올라갈 때 처음 만나는 불균형 노드를 A라고 하면, 불균형 유형은 다음 네 가지이다.

| 유형 | 삽입 경로 | 복구 방법 |
|---|---|---|
| LL | 왼쪽 자식의 왼쪽 서브트리 | `A`를 오른쪽으로 회전 |
| RR | 오른쪽 자식의 오른쪽 서브트리 | `A`를 왼쪽으로 회전 |
| LR | 왼쪽 자식의 오른쪽 서브트리 | 왼쪽 자식을 왼쪽 회전한 후 `A`를 오른쪽 회전 |
| RL | 오른쪽 자식의 왼쪽 서브트리 | 오른쪽 자식을 오른쪽 회전한 후 `A`를 왼쪽 회전 |

LL·RR은 한 번의 회전, LR·RL은 두 번의 회전으로 처리한다.

### 삽입과 삭제

삽입은 다음 순서로 처리한다.

1. 일반 BST 규칙으로 새 키를 삽입한다.
2. 삽입 위치에서 루트 방향으로 높이와 균형 인수를 갱신한다.
3. 처음 발생한 불균형을 적절한 회전으로 복구한다.

AVL 삽입에서는 처음 발견한 불균형 지점을 복구하면, 그 서브트리의 높이가 삽입 전 높이로 돌아온다. 따라서 추가 회전은 필요하지 않다.

삭제는 일반 BST 삭제 후 균형을 복구한다.

- 자식이 없으면 노드를 제거한다.
- 자식이 하나면 그 자식으로 대체한다.
- 자식이 둘이면 중위 후속자 또는 중위 선행자로 대체한 뒤 해당 노드를 제거한다.

삭제는 서브트리의 높이를 줄일 수 있어 여러 조상에서 연속으로 회전이 필요할 수 있다.

### 시간 복잡도

AVL 트리는 높이가 O(log n)이므로 검색, 삽입, 삭제 모두 최악의 경우 O(log n)을 보장하며, 회전 한 번에는 O(1)을 보장한다.

## 최적 이진 탐색 트리와 AVL 트리 비교

최적 이진 탐색 트리는 주어진 검색 확률에서 평균 비용을 줄이는 방법이고, AVL 트리는 데이터가 변경되어도 최악의 연산 시간을 안정적으로 유지하는 방법이다.
